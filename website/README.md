# SproutBook woodland showcase

Live website: https://sproutbook-woodland.nothatch.chatgpt.site

Static HTML/CSS/JavaScript with one connected woodland journey: sunrise canopy,
memory oak, calendar noticeboard, feeding picnic, evening nursery, growing
sapling and nighttime arrival. Four depth layers and supplied SVG timelines
follow native scroll position in both directions. Normal page scrolling remains
available; reduced motion and the persistent motion-off switch show all content
in a still reading layout.

The top and final download links point to the current native Android evaluation
release. Actual native screenshots use synthetic family data; older screenshots
retain their version labels. Interactive memory, feeding, tooth and stage demos
use temporary sample state. The request form prepares a GitHub issue for visitors
to review and submit.

The hosted site is managed through its existing Sites project. This folder is
the public website-source mirror; editing it alone does not publish the live
website. Runtime art, CSS and controllers are mirrored, while APK/source archives
are hosted downloads rather than committed copies. See `QA-JOURNEY.md` for the
woodland implementation and `QA-3.6.md` for the current download/gallery update.
