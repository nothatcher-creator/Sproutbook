# Native SproutBook rebuild — 3.0.0
The complete user brief is authoritative. Package com.nothatcher.sproutbook;
Kotlin, Compose, Room, DataStore; no WebView or Godot. Four tabs, child context,
warm forest theme, offline-first typed storage, guarded caregiver mode.

Phases, each compiled/tested before the next:
1. Foundation, profiles, theme, navigation
2. Today, memories and tree
3. Calendar and appointments
4. Feeding and formula
5. Sleep and native audio
6. Solids and weekly meals
7. Teeth and milestones
8. Pregnancy
9. Advice and immediate help
10. Inventory, emergency, health, caregiver mode
11. Backup/import, reminders, diagnostics
12. Polish, performance evidence, UI/device QA, release build

Review focus: child isolation, stale selection, caregiver bypass, imported numeric/date
validation, atomic import and milestone-memory updates, native gesture cancellation,
reminder opt-in, foreground audio lifecycle. Future cloud/iOS integration must preserve
UUID identities and typed records; pure logic is in :core.
