# SproutBook 3.5 woodland motion
Integrate the supplied Woodland Motion Pack into the native Kotlin/Compose application. Keep existing paintings, data, native gestures and accessible labels. Use selected-tab loops, restrained banner illustrations, low-opacity background fireflies, static pack icons in lists, finite button responses and an actual-save confirmation. Preserve Reduce motion defaults. Stop decorative motion during backgrounding, battery saver, disabled system animators, keyboard entry and loss of window focus. Only visible assets may play. Retain PNG fallback and original icon resources for unsupported mappings. Ship Lottie/PNG only, with provenance and font licence. Do not replace the interactive Memory Tree with decorative artwork. Version 3.5.0, same package/signing identity and database schema.
