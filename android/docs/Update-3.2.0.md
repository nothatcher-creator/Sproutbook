# SproutBook 3.2.0

This update extends the native family experience with three connected everyday tools.

## Routines & responsibilities

Create a child's routine with selected weekdays, an optional time, an owner and notes. Complete or undo it for a chosen past/current date, pause it without losing history, and edit or delete it with confirmation. Today shows the number remaining and opens the daily journal. All stages can use routines; changing stage keeps the records.

## Potty journal

Record a try, wet or dirty visit quickly, or manually record a mixed visit or accident with time and notes. Edit or remove entries and load older history. The toddler dashboard offers direct access. Language stays neutral: this is an observation journal, without scores or readiness promises.

## Milk freezer

Keep individual containers with original volume, stored time, location and notes. Frozen inventory shows its total and lists the oldest recorded containers first. A saved pumping session can create one linked container, once. Marking Used/Discarded moves it into history without inventing a feed. Changed drafts must save before status actions; historical records retain their original amount and allow notes edits.

Pumping links are protected against changing the source into a bottle or another child's record. Later edits to pump amounts do not rewrite the container's stored snapshot. No expiry, storage-duration or safety calculation is provided.

## Data and delivery

Four child-owned typed tables extend Room schema 10 to 11. Backup format 3 includes all 21 tables and continues to import complete format 1/2 backups. New records, selected tree positions and older records remain available offline. Grandparent mode guards actions at both UI and repository layers.

The package stays `com.nothatcher.sproutbook`, with version code `30200` and the same public development certificate as earlier evaluation builds. Release APK/AAB outputs remain unsigned for the owner's private upload key. Executed QA and its limits are recorded in `QA.md`; review findings and corrections are in `Review.md` and `v32-ledger.md`.
