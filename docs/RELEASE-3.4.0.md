# SproutBook 3.4.0 · Woodland preview

![SproutBook woodland release artwork](https://raw.githubusercontent.com/nothatcher-creator/Sproutbook/main/docs/assets/woodland-hero.jpg)

[Download Android APK](https://github.com/nothatcher-creator/Sproutbook/releases/download/V1.0/SproutBook-3.4.0-debug.apk) · [Installation guide](https://github.com/nothatcher-creator/Sproutbook/blob/main/docs/INSTALL.md)

A softer home for everyday parenting. This release brings the native Android app into a coordinated grassy woodland visual theme while retaining the existing care tools and local records.

## What's new

- Five original painted woodland scenes: background, Today, Schedule, Care, and More.
- Thirty-three custom SVG/native vector icons for tabs, features, and shared actions.
- Softer rounded cards, forest greens, moss accents, warm cream, and scalable serif headings.
- Matching dark and light native controls and illustrated tab headers.
- An optional subtle firefly background. Reduce motion is enabled by default.

## Included care tools

Multi-child profiles; Today dashboard; memory trees and timelines; calendar and appointments; bottle, nursing and pump logs; formula planning; sleep and eight native sounds; foods, reactions and weekly meals; visual teeth and milestones; pregnancy tools; searchable Mom/Dad advice and Help Right Now; routines, diapers, potty logs, milk freezer inventory, prepared bottles, shopping and supplies; health journal, emergency card, grandparent mode, backups and diagnostics.

## Validation and remaining work

The 3.4 build passed compilation, 79 unit tests, debug and unsigned release builds in the development session. Emulator checks covered navigation and care interactions. These are development results, not a claim of complete device or store certification.

This GitHub release is marked **pre-release** because the final large-text check, the system animation-setting fix, broader physical-device testing and production signing are still pending. The current optional-motion implementation can continue animating when Android's animation scale changes during use. Keep Reduce motion enabled for a static background.

Guidance remains educational. Clinical/editorial review and the remaining hardware/store checks are required before a general release. Cloud sync, shared caregiver accounts, and iOS are not included.
