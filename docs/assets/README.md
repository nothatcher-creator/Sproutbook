# Woodland assets

`woodland-hero.jpg` is original painted repository artwork generated with the built-in image tool for SproutBook. The brief was a soft grassy woodland meadow, moss, ferns, daisies, muted gold morning light, warm cream mist and deep forest silhouettes, with the SproutBook title and “A little calmer. A little more connected.” tagline. It is promotional artwork, not an app screenshot.

`today-art.jpg`, `schedule-art.jpg`, `care-art.jpg` and `more-art.jpg` are the actual offline tab illustrations from the native 3.4 app. The editable feature icons come from the same application's SVG asset set. The download button and meadow divider are native SVGs created for this repository.

The three `*-screen-v33.png` files are unmodified emulator captures of the 3.3 care update, using synthetic data. They are labelled as earlier screenshots in the README and are not presented as current 3.4 graphical captures.
