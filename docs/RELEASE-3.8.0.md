# SproutBook 3.8.0 · Leaves worth keeping

Tap a memory leaf to open a leaf-shaped keepsake card, with the story, photo,
date, child and chapter together. The timeline and Today tree open the same
view. Edit memory opens the existing editor; Close or Back returns to the previous view.
Long stories scroll, and Grandparent mode stays read-only.

Four new tree themes join Summer, Autumn and Night: Spring, Blossom, Winter
and Rainbow. Each child's profile previews the selected woodland before Save.
The scenes add seasonal details while preserving saved branch positions,
category colors, arranging gestures and accessible leaf actions.

The website's clearly labeled sample memory demo now lets you open a leaf card,
try the seven themes, and edit temporary sample stories.

Version 3.8.0 / code 30800 supports Android 8.0+ and retains the existing
evaluation signing identity. Install over your existing evaluation app to retain
local records. Keep a backup before updating. Room schema 13 and backup format
5 remain unchanged; 3.7 and earlier cannot restore exports containing the four
new tree theme names. Use 3.8 or newer for those exports.

This remains an evaluation prerelease. Native build and QA evidence is recorded
in [QA-3.8](../android/docs/QA-3.8.md). Real-device and spoken TalkBack checks,
Android 17 background behavior and production signing remain outside the
emulator verification.
